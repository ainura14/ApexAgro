## Чек-лист
- [ ] `./gradlew build` зелёный локально (тесты границ модулей, миграций и контрактов прошли)
- [ ] Код модуля в своём пакете: API в корне, реализация в `internal/`; к чужим модулям — только через их `XxxApi` и события
- [ ] Новые таблицы — миграцией `db/migration/<своя схема>/V<yyyyMMddHHmm>__описание.sql`, без FK на чужие схемы; применённые миграции не менял
- [ ] Ошибки — `ApiException` с кодом из своего enum `ErrorCode`, тексты в `messages_ru` и `messages_ky`
- [ ] Новые/изменённые эндпоинты описаны в `api/<module>.yaml`
- [ ] Деньги/количество — `Money`/`Quantity`, страницы — `PageResponse`, даты — `Instant` (UTC)
- [ ] В логах нет телефонов, ПИН, OTP-кодов и токенов в открытом виде
- [ ] `@Scheduled` — с `@SchedulerLock`
- [ ] Затронута зона тимлида (common, миграции, CI, конвенции) → нужен апрув тимлида; архитектурное решение → ADR в `docs/adr/`
